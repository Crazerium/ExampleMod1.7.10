# GTNH Bunnyhop

Stage 1 proof of concept for Minecraft 1.7.10 / GTNH.

Current features:
- Source-style air strafing and momentum preservation
- Auto-bhop while holding jump
- Bottom-center horizontal speed HUD in m/s
- Configurable air acceleration, air wish speed and maximum speed

The knife/first-person animation system is intentionally not part of Stage 1.
